## About
 
I'm a B.Tech CSE (AI & ML) student at K.R. Mangalam University, and I’ve been building on GitHub since 2020. My work centres on agentic AI systems, multimodal pipelines, and tools that run under real resource constraints (limited VRAM, flat RAM, no network access).
 
Alongside my degree I do freelance AI evaluation work, which has sharpened how I think about LLM reliability and reasoning errors. I'm working toward launching my ideas into the real world.
 
## Selected Work
 
### Kavach AIDR
Air-gapped vulnerability remediation pipeline built to run on a 4 GB VRAM budget.
`GraphSAGE` `Z3` `Local LLM` `AST/CFG`
 
### Filmy-AI
Resource-optimised multimodal video editing engine.
`Gemini 2.5 Flash` `FastAPI` `MoviePy` `FFmpeg`
 
### SounZ AI
NLP-to-DSP compiler that turns natural-language commands into sample-accurate audio operations, from basic edits to advanced processing.
`FastAPI` `Coqui XTTS v2` `Demucs` `SciPy`
 
### HITS: Hygiene Issue & Tracking System
Sanitation supervision platform for Schools. Workers send photo proof over WhatsApp, receive automated Hindi confirmations, and the supervisor's dashboard updates live.
`Node.js` `WhatsApp Cloud API` `Socket.io` `React` `MongoDB`
 
### Code-Runner and Astro Dude
Code-Runner is an open-source adaptive coding-challenge platform that I led a 4-person team to build. [Astro Dude](https://github.com/Programmer-Develops/astro-dude) is a space education and live meteor-tracking app with a Gemini chatbot, published on the Google Play Store.
`Next.js` `React Native` `NASA API`
 
### Other builds
[Antivus IO](https://antivus-io.onrender.com/) (real-time multiplayer survival game, Socket.io) and [Bajrangi AI](https://github.com/Programmer-Develops/bajrangi-ai) (indigenous chatbot experiment).
